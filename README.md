# Full Automation Framework

This repository is intended to provide an automation framework for testing applications using Selenium and Cucumber.

## Features
- Easy setup
- Comprehensive documentation
- Scalable architecture

## Getting Started

### Prerequisites
- Java 8 or above
- Maven
- ChromeDriver

### Installation
1. Clone the repository
2. Run `mvn install` to install dependencies.

### Running Tests
- Execute tests using `mvn test`
